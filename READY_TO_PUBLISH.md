## Quick Publish Guide

### 1. Login to npm (First Time Only)

```bash
npm login
```

You'll need:
- npm username
- npm password
- npm email

**Don't have an npm account?** Create one at https://www.npmjs.com/signup

### 2. Publish

```bash
cd paas/ugahost-cli
npm publish --access public
```

That's it! 🎉

### 3. Verify

```bash
npm view ugahost
```

Or visit: https://www.npmjs.com/package/ugahost

## After Publishing

Users worldwide can install with:

```bash
npm install -g ugahost
```

Then use it:

```bash

```
